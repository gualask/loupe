# Security policy

Loupe hosts HTML uploaded by its users, so isolating that HTML from the app is part of its design:
see [`docs/SPEC.md`](docs/SPEC.md) §4. Reports of anything that weakens that isolation, or any
other vulnerability, are welcome.

## Supported versions

Loupe is in early release (0.x). Fixes go into the latest release only; update to it before
reporting.

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/gualask/loupe/security/advisories/new),
not in a public issue. Include the Loupe version, how to reproduce the problem and what it allows.

You will get an answer within a week. Once a fix is released, the advisory is published with
credit to the reporter, unless they prefer otherwise.
